# 🌧️ Rain Alert Automation

A Python-based automated rain alert system that uses the OpenWeather API to check the weather forecast and sends an email notification when rain is expected.

## 🚀 Features

- 🌦️ Checks weather forecast automatically
- 🌧️ Detects expected rain
- 📧 Sends an email rain alert
- 🤖 Runs automatically using GitHub Actions
- 🔐 Uses GitHub Secrets to protect API keys and passwords

## 🛠️ Technologies Used

- Python
- OpenWeather API
- Gmail SMTP
- GitHub Actions
- Requests Library

## ⚙️ How It Works

1. Fetches weather forecast from OpenWeather API.
2. Checks the weather conditions.
3. Detects whether rain is expected.
4. Sends an email alert if rain is detected.
5. GitHub Actions runs the script automatically on schedule.

## 📌 Purpose

This project helps users receive automatic rain alerts without manually checking the weather every day.
